# Estribo brand assets

Arquivos oficiais disponíveis para uso imediato na landing pública:

- `logo-estribo-horizontal.png`
  - Logo principal para header claro.
  - Uso atual em `templates/site_publico/base_public.html`.

- `logo-estribo-horizontal-white.png`
  - Logo para footer e fundos escuros.
  - Não aplicar inversão de cor por CSS.

- `simbolo-estribo.png`
  - Símbolo isolado oficial/conceitual.
  - Reservado para usos compactos futuros.

- `favicon-32.png`
  - Favicon PNG 32 x 32 px.

- `apple-touch-icon.png`
  - Ícone 180 x 180 px para dispositivos Apple.

- `app-icon-512.png`
  - Ícone institucional em alta resolução para uso futuro.

Quando houver SVGs vetoriais finais, eles podem substituir os PNGs em uma etapa própria. Até lá, a landing deve apontar para os PNGs físicos existentes.
